# HexTactics

Тактическая игра на гексагональной карте в реальном времени с паузой для
Windows 10/11 x64. Бойцы, навыки, эффекты клеток, состояния, синергии, карты
и сценарии описываются данными (JSON) и редактируются во встроенном
визуальном редакторе без изменения кода.

![Бой: маршрут из нескольких точек с действиями в очереди](docs/img/battle.jpg)

Графика минималистичная, но объёмная: гексы — призмы с фаской и уровнями
высоты, фишки юнитов со стрелкой взгляда, камера смотрит на поле «как на
стол» под наклоном 60° (настраивается от 35° до 89°).

## Что есть

* **Время**: фиксированный тик 20/с, пауза и скорости 0.25×/0.5×/1×/2×/4×,
  шаг по одному тику, автопауза по событиям (настраивается). Результат не
  зависит от FPS и скорости, бой воспроизводим по seed.
* **Юниты**: 6 направлений взгляда, очки действия (ОД) с резервом в
  очереди, постепенное движение, A* по минимальной стоимости с учётом
  высоты, местности, эффектов и занятости.
* **Очередь команд**: маршрут из нескольких точек, действия в любой
  промежуточной точке (навык, поворот, стойка, ожидание), перестановка и
  удаление, политики при неудаче (ждать / пересчитать путь / пропустить /
  отменить очередь) с ограничением ожидания.
* **Навыки**: подготовка, восстановление, перезарядка, прерывания с
  возвратом ОД, многоэтапные эффекты, области `Single / Line / Cone / Sector
  / Radius / Ring / Cross / Chain / Mask / Global` с поворотом по 6
  направлениям, предпросмотр области и целей (включая союзников под
  ударом), телеграфирование вражеских навыков.
* **Бой**: секторы атаки (фронт / ближний фланг / дальний фланг / тыл) с
  шансами «заметить» и «неожиданности», попадание, блок, крит, типы урона,
  сопротивления, уязвимости, иммунитеты, линия видимости, туман войны.
* **Эффекты клеток и состояния**: огонь, яд, лёд, дым, вода, электричество
  и др. Наложение поверх местности (не заменяет её), уровни,
  распространение, накопительные состояния с порогами и спадом. Синергии
  (огонь + газ → взрыв, искра + вода → электризация…) с защитой от
  бесконечных цепочек.
* **ИИ**: профили поведения (агрессия, дистанция, отступление, выбор
  цели, использование навыков, охрана позиции, наступление), использует те
  же команды и правила, что и игрок; в административном режиме видно, на
  кого и почему он нацелен.
* **Административный режим**: редакторы карт (кисти, высота, метки,
  проверка достижимости), юнитов и врагов (с 3D-предпросмотром), навыков
  (гекс-поле с юнитом в центре, клик по клеткам, эффекты отдельных клеток,
  этапы, превью и тест), эффектов клеток, состояний, таблицы синергий,
  пассивок, ресурсов, характеристик, типов урона, фракций, профилей ИИ,
  правил боя (с безопасными формулами), сценариев (стороны, волны,
  триггеры, условия победы/поражения); проверка контента с переходом к
  ошибке, переименование с обновлением ссылок, импорт/экспорт отдельных
  объектов, резервные копии, автосохранение черновика, тестовый бой на
  черновике.
* **Диагностика**: журнал боя (основной / подробный / диагностический),
  панель F3 с FPS, тиками, числом юнитов/эффектов/синергий, временем
  подсистем симуляции.

* **Часть 2**: шаблоны карт, объёмное high-tech оформление и типы
  местности, ямы, слои существ (наземные, воздушные, подземные), модели
  взгляда врагов и раскрытие сведений, совместное размещение и
  блокирование, автоатаки, единый расчёт урона с элементами и щитами,
  сценарии с целями, волнами и маршрутами, библиотека контента с версиями,
  пакеты `.hexpack` с зависимостями, редактор операций без кода.
* **Часть 3**: управление стрелкой взгляда (короткий жест — поворот,
  длинный — маршрут, направление после движения) с автопаузой при
  планировании; приказ по гексу врага и радиальное меню навыков с
  защитным навыком в центре; прицельные и автоматические навыки с
  правилами выбора цели и политиками потери цели; групповые приказы
  (рамка, группы Ctrl/Alt+цифра, распределение позиций без конфликтов,
  заторы, формации); многоударные навыки с параметрами каждого удара,
  условиями и стоимостью; пассивы и таланты с происхождениями, условиями
  и единым суммированием модификаторов; импорт визуальных ресурсов с
  анализом и лимитами (PNG/JPEG/WebP/TGA/HDR/EXR, glTF/GLB/FBX/OBJ,
  WAV/OGG/MP3), привязки к местности, юнитам, навыкам и эффектам,
  снаряды, маркеры анимаций, страница «Требования к ресурсам».
* **Часть 4** (идёт по этапам, [docs/STAGES.md](docs/STAGES.md)): рабочее
  место «TD-сцена» — базы игрока и спавна из нескольких гексов,
  маршруты, нарисованные протяжкой мыши с проверкой проходимости,
  группы волн у баз спавна, урон по базе и поражение по базам; граф
  маршрутов с развилками и петлями; дерево категорий существ; автобой —
  TD с расстановкой, свободный бой и автотест, профили ИИ «если — то —
  иначе», события сценария, отчёт прогона и пакетные прогоны.

Принятые правила и значения по умолчанию —
[docs/DECISIONS.md](docs/DECISIONS.md), расширения частей 2–4 —
[DECISIONS_2.md](docs/DECISIONS_2.md), [DECISIONS_3.md](docs/DECISIONS_3.md) и

## Требования

* [.NET SDK 8](https://dotnet.microsoft.com/download) (ядро и тесты).
* [Godot 4.4.1 .NET](https://godotengine.org/download/archive/4.4.1-stable/)
  (обязательно сборка **.NET / mono**) — для запуска игры и экспорта.
* Для экспорта: шаблоны экспорта Godot 4.4.1 mono
  (`Godot_v4.4.1-stable_mono_export_templates.tpz`; в редакторе:
  *Editor → Manage Export Templates*).

## Быстрый старт

```bash
# тесты ядра (без Godot)
dotnet test tests/HexTactics.Tests

# запуск игры из исходников
cd game
dotnet build
godot --path .            # или открыть game/project.godot в редакторе Godot и нажать F5
```

В главном меню: выбор сценария («Засада в долине», «Арена», «Полигон» —
песочница для проверки навыков и синергий, «Слизистое болото» — пассивы и
таланты, «Логово титана», «Блокпост» и другие), **Административный режим**
(редактор) и настройки.

## Сборка для Windows

Из редактора: *Project → Export… → Windows Desktop → Export Project*.

Из командной строки (работает на Windows и Linux):

```bash
mkdir -p build/windows             # Godot не создаёт папку назначения сам
cd game
godot --headless --path . --import      # только для свежего клона (нет папки .godot)
godot --headless --path . --export-release "Windows Desktop"
```

Результат — папка `build/windows/`:

```
HexTactics.exe                       запускаемый файл
HexTactics.pck                       ресурсы и встроенный контент (JSON)
data_HexTactics_windows_x86_64/      сборки .NET (рантайм входит в комплект)
```

Распространять нужно **всю папку** целиком; установка .NET на
компьютере игрока не требуется. Аналогично `--export-release "Linux"`
собирает `build/linux/` (папку тоже нужно создать заранее).

Сборку для Windows также делает CI
([.github/workflows/build.yml](.github/workflows/build.yml)): тесты →
экспорт Windows и Linux → самотест Linux-сборки → артефакт
`HexTactics-windows-x64`.

### Проверка сборки

```bash
HexTactics.exe --headless -- --selftest     # контент без ошибок + 30 с симуляции каждого сценария
HexTactics.exe -- --uitest                  # сквозные UI-тесты: клики и клавиши через Input
```

Код возврата 0 — успех, 1 — ошибка; итог печатается строкой
`SELFTEST: OK` / `UI TESTS: ALL PASSED`.

Если на компьютере нет Vulkan, игра запускается с OpenGL:
`HexTactics.exe --rendering-driver opengl3`.

## Управление в бою

| Клавиша / мышь | Действие |
|---|---|
| Пробел | пауза / продолжить |
| Z / X, − / + | скорость медленнее / быстрее |
| `.` | один тик (на паузе) |
| ЛКМ по своему юниту | выбрать: стрелка взгляда и панель команд (автопауза — по настройке); Tab — следующий |
| Shift+ЛКМ, рамка ЛКМ | выделить несколько; приказ выделенным — групповой |
| Ctrl+1…9 / Alt+1…9 | сохранить / выбрать группу |
| Стрелка взгляда | короткий жест — поворот; длинный — маршрут по гексам, в конце — направление после движения |
| Жест или ЛКМ на враге, R | радиальное меню навыков против цели (защитный навык в центре) |
| M | движение: несколько ЛКМ = маршрут |
| ЛКМ по номеру точки маршрута | действие после этой точки (навык, поворот, стойка…) |
| T · F · 1–9 | поворот · атака · навыки (автоматический навык — сразу) |
| B / H | защитная стойка / ожидание |
| Backspace · Delete · Shift+Delete | убрать последнюю точку · ожидающие приказы · отменить всё |
| ПКМ | быстрый приказ; во время жеста — отмена |
| Esc | шаг назад: жест → режим → выделение → меню |
| WASD / стрелки / средняя кнопка / край экрана | камера |
| Колесо, PgUp/PgDn · Q/E · Home · V | зум · поворот на 60° · к выбранному юниту · вписать карту |
| I · L · F1 · F3 | характеристики · журнал · справка · диагностика |

Полная справка с обозначениями — кнопка «?» в бою.

## Где хранится контент

* **Встроенный пакет** — `game/content/` (в сборке — внутри `.pck`,
  только для чтения).
* **Пользовательский пакет** — пишется редактором при сохранении в папку
  данных пользователя: на Windows
  `%APPDATA%\Godot\app_userdata\HexTactics\content\`. Если он есть, игра
  загружает его вместо встроенного; кнопка «К встроенному» в редакторе
  возвращает встроенный (старый пакет сохраняется копией).
* **Резервные копии** — `…\content\backups\<дата_время>\` перед каждой
  перезаписью.
* **Автосохранение черновика** — `…\autosave\` (предлагается восстановить
  при следующем входе в редактор).

Формат файлов, версии и миграции — [docs/DATA_FORMAT.md](docs/DATA_FORMAT.md).

## Параметры командной строки

Параметры игры указываются после `--`:

| Параметр | Назначение |
|---|---|
| `--selftest` | самотест сборки (см. выше) |
| `--uitest[=имя]` | UI-тесты (все или один по имени) |
| `--auto=battle --scenario=<id> [--seed=N] [--admin]` | сразу открыть бой |
| `--auto=editor [--tab=skills] [--select=<id>]` | сразу открыть редактор |
| `--run=<сек>` · `--speed=<0..4>` | прогнать бой N секунд и поставить на паузу · скорость |
| `--shot=<файл.png> [--frames=N]` | сохранить скриншот на кадре N и выйти |
