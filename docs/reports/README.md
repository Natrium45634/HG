# Экспортированные отчёты (часть 5, ТЗ §42.3)

Это примеры отчётов из встроенного контента. Их создают те же функции, что
и кнопки редактора: `AutoBattle.Save` (пакет и бой) и калибровка из
«Обзора проекта». CSV — RFC 4180, UTF-8 с BOM.

| Файл | Что это |
|---|---|
| `td_pass_100runs.*` | пакет из 100 прогонов «Оборона перевала (TD)», seed 1000…1099: сводка (`.txt`, `.json`, `_summary.csv`), строка на прогон (`_runs.csv`), волны (`_waves.csv`) |
| `td_pass_worst_seed1084.*` | худший прогон пакета: полный отчёт боя, юниты, волны |
| `calibration_sample.*` | калибровка оценки силы: 36 пар эталонов × 6 боёв, прогноз против доли побед |

Чтобы открыть их в разделе «Результаты», скопируйте `.json` и
`calibration_*.csv` в папку отчётов (`user://reports`) и нажмите
«Обновить».
