# Гекс-тактика 1.1.0

Тактика на гексагональной карте в реальном времени с паузой и встроенный
редактор всего игрового контента без программирования. Выпуск 1.1.0
добавляет части 5 и 6 технического задания к выпуску 1.0.0 (части 1–4).

## Что скачать (Windows 10/11 x64)

| Файл | Как пользоваться |
|---|---|
| **HexTactics-1.1.0-Setup.exe** | установщик — запустить и нажимать «Далее». Права администратора не нужны; ярлыки в «Пуске» и на рабочем столе; удаление через «Параметры → Приложения». Установка поверх 1.0.0 обновляет игру. |
| **HexTactics-1.1.0-Portable.exe** | один файл без установки — просто запустить (с рабочего стола, флешки). |
| HexTactics-1.1.0-Linux-x64.tar.gz | для Linux x64: распаковать, запустить `linux/HexTactics.x86_64`. |
| Руководство пользователя (RU).txt | установка, управление, редактор, что делать при проблемах. |

Файлы не подписаны цифровой подписью, поэтому при первом запуске Windows
может показать «Система Windows защитила ваш компьютер»: «Подробнее» →
«Выполнить в любом случае». Устанавливать .NET не нужно. Если игра не
открывается на старой видеокарте — ярлык «Гекс-тактика (безопасный режим
графики)» в меню «Пуск».

**Обновление с 1.0.0.** Если в 1.0.0 вы публиковали свой контент в
редакторе, игра продолжит открывать ваш пакет — новых сценариев («Два
прохода» и др.) в нём нет. Чтобы увидеть встроенный контент 1.1.0: в
редакторе нажмите «Встроенный» — ваш пакет сохранится резервной копией
(папка `content_backup_…` в данных пользователя).

## Что нового в 1.1.0

**Часть 6 — режимы, отряд, развёртывание и новые системы боя**

* Правила режима: свободная RTS, тактический TD, гибрид; свои значения
  сценария; каждая подсистема выключается отдельно.
* Отряд перед боем и вызов бойцов за очки развёртывания во время боя:
  зоны, направление постановки, отзыв, перерывы, лента отряда.
* Блокирование с ёмкостью и весом, прорыв навыком; модификаторы миссии и
  варианты сложности; интерактивные объекты (ворота, мосты, рычаги,
  турели); граф событий с отладкой; фазы босса и телеграфы атак;
  кампании с наградами.
* Шкалы (боевой дух, санити) с паникой; дружественный огонь по видам
  воздействия с подсветкой и подтверждением «Удар по своим»; призыв
  существ с простым ИИ (охрана, следование, атака цели хозяина…).
* Переназначение клавиш («Настройки → Клавиши…»); проверка контента с
  кодом, местом и исправлением, автоисправление безопасных проблем.
* Демоуровень «Два прохода» и кампания «Два прохода»; кампания «Перевал».

**Часть 5 — инструменты автора**

* JSON Schema контента, неизвестные поля сохраняются; обзор проекта.
* Редактор карты и TD: инструменты, слои, спавн по волнам; режимы
  сценария (штурм, смешанный, сопровождение, песочница).
* ИИ и симулятор: строгость маршрута, unsafe-тест, сброс к снимку,
  реплей, телеметрия и CSV; экран «Результаты» со сравнением прогонов.
* Теги и категории с несколькими родителями, наложение пассивов,
  «не хочет / не может», масса и столкновения.
* Автосборка юнитов по бюджету, кэш оценки силы, калибровка; вкладки
  редактора юнита; превью материалов на гексах.

## Что было в 1.0.0

Бой в реальном времени с паузой, объёмная гекс-карта, туман войны;
навыки, области, единый расчёт урона, эффекты клеток, состояния,
синергии, пассивы и таланты; ИИ с профилями; оборона баз (TD); автобой и
пакетные прогоны; оценка силы; редактор с черновиком, версиями,
отменой, импортом ресурсов и пакетами `.hexpack`.

Полное описание — README.md в репозитории.

## Проверено

* 638 автоматических тестов ядра; 70 тестов интерфейса (Linux), в том
  числе экран 1920×1080 и 2560×1440 и масштаб интерфейса 2.
* Самопроверка каждой сборки (контент, ресурсы, 30 с симуляции каждого
  сценария) на Windows Server; установщик проверен там же: тихая
  установка → файлы и ярлыки → запуск → удаление.
* Запуск с окном на настоящей Windows 10/11 автоматически не проверяется.
