# Гекс-тактика 1.0.0

Первый выпуск: тактика на гексагональной карте в реальном времени с
паузой и встроенный редактор всего игрового контента без программирования.

## Что скачать (Windows 10/11 x64)

| Файл | Как пользоваться |
|---|---|
| **HexTactics-1.0.0-Setup.exe** | установщик — запустить и нажимать «Далее». Права администратора не нужны; ярлыки в «Пуске» и на рабочем столе; удаление через «Параметры → Приложения». |
| **HexTactics-1.0.0-Portable.exe** | один файл без установки — просто запустить (с рабочего стола, флешки). |
| HexTactics-1.0.0-Linux-x64.tar.gz | для Linux x64: распаковать, запустить `linux/HexTactics.x86_64`. |
| Руководство пользователя (RU).txt | установка, управление, редактор, что делать при проблемах. |

Файлы не подписаны цифровой подписью, поэтому при первом запуске Windows
может показать «Система Windows защитила ваш компьютер»: «Подробнее» →
«Выполнить в любом случае». Устанавливать .NET не нужно. Если игра не
открывается на старой видеокарте — ярлык «Гекс-тактика (безопасный режим
графики)» в меню «Пуск».

## Что внутри

* Бой в реальном времени с паузой (×0,25…×16, шаг по тику), объёмная
  гекс-карта, камера под наклоном, туман войны, линия видимости.
* Отряды: направление взгляда, очки действия, маршруты из нескольких
  точек с действиями, стрелка взгляда (жесты), радиальное меню атак,
  группы и формации.
* 45 навыков, серии ударов, области 10 форм, единый расчёт урона
  (элементы, типы урона, броня, щиты, криты, блок), 16 эффектов клеток,
  25 состояний, 11 синергий, пассивы и таланты, дерево категорий существ.
* ИИ с профилями и правилами «если — то — иначе»; 13 сценариев с
  волнами, боссами и триггерами.
* Оборона баз (TD): базы, маршруты с развилками, слияниями и петлями,
  волны из групп, расстановка защитников.
* Автобой и пакетные прогоны с подробным отчётом; оценка силы и уровня
  юнитов, «Подогнать под уровень», стоимость угрозы для волн.
* Редактор: черновик и публикация с версиями, отмена/повтор, журнал и
  точки восстановления, массовые изменения, проверка сценария, отчёт по
  волнам, импорт ресурсов, обмен пакетами `.hexpack`.

Полное описание — README.md в репозитории.

## Проверено

* 434 автоматических теста ядра; 47 тестов интерфейса (Linux).
* Самопроверка каждой сборки (контент, ресурсы, 30 с симуляции каждого
  сценария) на Windows Server; установщик проверен там же: тихая
  установка → файлы и ярлыки → запуск → удаление.
* Одиночный exe запускался с окном под Wine (меню, бой, редактор).
* Запуск с окном на настоящей Windows 10/11 автоматически не проверяется.
